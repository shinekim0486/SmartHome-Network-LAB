WIRESHARK LAB

Wireshark 패킷 관찰소

온라인 주행 데이터에서 찾은 움직임을 실제 네트워크 패킷의 관찰·필터·증거 기록으로 연결합니다.

Wireshark 중심
01 · 캡처 준비

관찰 대상 정하기

학생이 실행할 웹 요청이나 Python 예제를 하나 정하고, 시작 전 최초 판단을 먼저 기록합니다.

  1. 관찰할 요청·주소를 정하기
  2. Wireshark 캡처 시작
  3. 실행 후 캡처를 중지하고 pcapng로 저장
Wireshark 공식 문서 열기 교사 안내: 본인 실습 장치의 트래픽만 캡처하고, 다른 사람의 통신은 캡처하지 않습니다.
02 · 필터 관찰

Display Filter로 좁히기

전체 캡처에서 필요한 패킷만 필터링하고, 패킷 번호·출발지·목적지·프로토콜을 기록합니다.

tcp ip.addr == 127.0.0.1 tcp.port == 8001 Wireshark 필터 문서
03 · 증거 기록

패킷에서 판단 만들기

필터 결과를 화면 캡처하고, 관찰 사실과 학생의 최종 판단을 분리해 기록합니다.

  1. 프레임 번호를 적기
  2. 눈에 띄는 필드를 한 문장으로 설명
  3. 처음 판단과 비교해 수정·재검증
증거 기록으로 이동 권장 산출물: pcapng 파일, 필터 문자열, 화면 캡처, 판단 문장
