# 06차시 — TShark 자동 분석

## 오늘의 미션

GUI 관찰을 재현 가능한 명령줄 증거로 바꾼다.

## 성공 조건

- VS Code 터미널에서 예제를 오류 없이 실행한다.
- Wireshark 패킷과 TShark 출력에서 같은 사실을 확인한다.
- Gemini에는 정답 대신 검증 질문을 요청하고, 최종 판단은 직접 쓴다.

## 활동

tshark/README.md 명령을 자신의 인터페이스에 맞게 수정해 실행한다.

## 증거

명령, 추출 필드, 결과 3줄 이상과 GUI 관찰이 일치하는지 기록한다. docs/evidence-template.md를 복사해 작성한다.

## Gemini 힌트 프롬프트

“나는 TShark 자동 분석을 관찰 중이다. 개인정보를 제거한 아래 증거에서 내가 놓친 필드와 검증 질문 3개만 알려줘. 결론은 말하지 마.”

## 수정·재검증

포트, 메시지, 장치 상태 또는 표시 필터 중 하나만 바꾼다. 무엇을 바꿨는지와 결과 변화를 기록한다.
