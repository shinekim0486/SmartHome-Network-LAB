# 02차시 — TCP 연결

## 오늘의 미션

TCP 서버와 클라이언트 사이 연결 수립과 데이터 전달을 구분한다.

## 성공 조건

- VS Code 터미널에서 예제를 오류 없이 실행한다.
- Wireshark 패킷과 TShark 출력에서 같은 사실을 확인한다.
- Gemini에는 정답 대신 검증 질문을 요청하고, 최종 판단은 직접 쓴다.

## 활동

tcp_server.py를 먼저 실행하고 tcp_client.py를 실행한다. 표시 필터는 tcp.port == 9000.

## 증거

SYN, SYN/ACK, ACK와 데이터 프레임을 골라 플래그·순서와 의미를 설명한다. docs/evidence-template.md를 복사해 작성한다.

## Gemini 힌트 프롬프트

“나는 TCP 연결을 관찰 중이다. 개인정보를 제거한 아래 증거에서 내가 놓친 필드와 검증 질문 3개만 알려줘. 결론은 말하지 마.”

## 수정·재검증

포트, 메시지, 장치 상태 또는 표시 필터 중 하나만 바꾼다. 무엇을 바꿨는지와 결과 변화를 기록한다.
