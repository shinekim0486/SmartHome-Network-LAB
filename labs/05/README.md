# 05차시 — 조명·도어 상태 제어

## 오늘의 미션

API 명령이 장치 상태 전이로 이어지는지 검증한다.

## 성공 조건

- VS Code 터미널에서 예제를 오류 없이 실행한다.
- Wireshark 패킷과 TShark 출력에서 같은 사실을 확인한다.
- Gemini에는 정답 대신 검증 질문을 요청하고, 최종 판단은 직접 쓴다.

## 활동

control_light.py, control_door.py를 실행하고 /api/devices 결과를 확인한다.

## 증거

명령 전후 상태, 요청 메서드, 응답 본문을 연결해 성공 여부를 판단한다. docs/evidence-template.md를 복사해 작성한다.

## Gemini 힌트 프롬프트

“나는 조명·도어 상태 제어을 관찰 중이다. 개인정보를 제거한 아래 증거에서 내가 놓친 필드와 검증 질문 3개만 알려줘. 결론은 말하지 마.”

## 수정·재검증

포트, 메시지, 장치 상태 또는 표시 필터 중 하나만 바꾼다. 무엇을 바꿨는지와 결과 변화를 기록한다.
