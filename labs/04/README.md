# 04차시 — HTTP 센서 API

## 오늘의 미션

Python 프로그램의 HTTP 요청과 FastAPI 응답을 연결한다.

## 성공 조건

- VS Code 터미널에서 예제를 오류 없이 실행한다.
- Wireshark 패킷과 TShark 출력에서 같은 사실을 확인한다.
- Gemini에는 정답 대신 검증 질문을 요청하고, 최종 판단은 직접 쓴다.

## 활동

FastAPI 서버를 켜고 read_sensor.py를 실행한다. 표시 필터는 tcp.port == 8000.

## 증거

요청 방향, 응답 방향, 상태 코드 또는 TCP 스트림을 증거로 기록한다. docs/evidence-template.md를 복사해 작성한다.

## Gemini 힌트 프롬프트

“나는 HTTP 센서 API을 관찰 중이다. 개인정보를 제거한 아래 증거에서 내가 놓친 필드와 검증 질문 3개만 알려줘. 결론은 말하지 마.”

## 수정·재검증

포트, 메시지, 장치 상태 또는 표시 필터 중 하나만 바꾼다. 무엇을 바꿨는지와 결과 변화를 기록한다.
